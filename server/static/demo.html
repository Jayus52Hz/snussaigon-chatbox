Chỉ riêng chatbox.

Giao diện thử độc lập dùng server và kiến thức đã tách từ dự án. Bấm nút chat ở góc dưới hoặc bắt đầu bên dưới.

Đang kiểm tra server…

Không có API key: thử giao diện với phản hồi mẫu. Để thử AI, điền ANTHROPIC_API_KEY và MODEL trong .env, rồi khởi động lại server.
